# Constraints

Node.js 24 LTS, npm lockfiles and ECMAScript modules; React/Vite/TypeScript/TanStack frontend;
Express 5/Zod/Pino/OpenAPI/pg backend. Supabase Auth UUIDs are profile/ownership identities.
SQL migrations are schema truth, with runtime validation for JSONB and no ORM.

Keep API authorization, closed RLS, transactional mutations, direct content identities, permanent
use locks, immutable snapshots, deterministic grading, fractional points and exactly-one feedback
FKs. Public authoring, privileged course editing, fuzzy evaluation, generalized work queues and
orchestration remain deferred. Changes after content use require independent replacement records.
