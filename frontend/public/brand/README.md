# Quiz Builder branding

`quiz-builder.png` is the transparent mascot used in the site header and home page.
The matching favicon PNGs and Apple touch icon live in the parent public directory.
The wordmark is live text styled in `src/styles.css` to support both color themes.

Generated using the built-in imagegen tool. PNG sizes were derived from the same
generated artwork, preserving transparency.

## Generation prompt

Use case: logo-brand

Asset type: square transparent website logo mark and favicon for Quiz Builder, a friendly study quiz creation app.

Primary request: Create a delightful bold mascot logo: a single chunky emerald-green rounded quiz card, slightly tilted, with a large creamy-white question mark on its face and a small golden-yellow builder's hard hat perched on top. The dot of the question mark suggests a cheerful little face with two tiny dark eyes, subtly playful. Simple memorable silhouette, professional polished flat vector-like illustration, rounded corners, thick clean dark forest-green outlines, minimal shapes, no texture, no gradients, no drop shadow. Fits existing warm cream/forest green UI and dark purple UI.

Composition: one centered compact icon filling 85% of a square, all elements within generous safe edges. Clear at 32px. Actual transparent background.

Constraints: icon only, no wordmark, no letters or text other than the question mark, no additional objects, no watermark, no mockup.
